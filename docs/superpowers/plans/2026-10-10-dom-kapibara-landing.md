# Лендинг «Дом Капибара» — план реализации

> **Для исполнителя:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development (рекомендуется) или superpowers:executing-plans. Шаги отмечены чекбоксами `- [ ]`.

**Цель:** доработать существующий черновик [index.html](../../../index.html) до готовой одностраничной визитки с вариантом первого экрана A, реальными фото, ссылками на Restoplace/Telegram/Яндекс Карты и заглушками там, где данных нет.

**Архитектура:** один статический `index.html` (CSS и мелкий JS внутри), картинки в `assets/img/`, отдельная `404.html` (уже готова). Без фреймворков и сборки. Проверки — `node --test` на чтении HTML, плюс ручной просмотр в браузере.

**Стек:** HTML, CSS (`animation-timeline: view()` под `@supports`), ванильный JS, Node 18+ (`node:test`) только для проверок.

**Спек:** [tz.md](../../../tz.md) (разделы 0, 0а, 0б — главные), [research.md](../../../research.md).

## Global Constraints

- Название бренда: «Дом Капибара». Продукт: «экскурсия».
- Цены: 2 100 ₽ (12:00–19:00 каждый час), 1 700 ₽ (11:00 и 20:00). Сертификат от 2 500 ₽, 3 месяца с даты активации. В hero: «от 1 700 ₽».
- Экскурсия 40 минут, группа до 15 человек, дети самостоятельно с 14 лет, по предварительной записи.
- Адрес: Сочи, ул. Егорова, 1/1Б. Телефон: +7 (988) 506-19-99 (`tel:+79885061999`).
- Ссылки: бронирование `https://domcapybar.restoplace.ws/`; Telegram `https://t.me/dom_capybar_sochi`; Яндекс Карты `https://yandex.ru/maps/org/dom_kapibar/230817806698/`, отзывы `.../reviews/`.
- Цвета: зелёный `#4f7f27` / тёмный `#355a18`, оранжевый `#f7931e`, фон `#fffaf0`; текст на оранжевых кнопках тёмный `#2f2418`.
- Шрифты: Unbounded (заголовки), Nunito (текст), `cyrillic`, `font-display: swap`; текст не меньше 16 px.
- Запрещено: слова «обнимашки», «на руках», «селфи»; превосходные степени («лучший», «единственный», «100%»); выдуманные цифры, отзывы с именами, счётчики срочности; Lenis, WebGL, автокарусели, автовидео со звуком, попапы.
- Разрешено писать «покормить» и «погладить» (подтверждено владельцем).
- Не больше двух залипающих элементов: шапка и нижняя панель (только мобильный).
- Все анимации — только `transform`/`opacity`, внутри `@media (prefers-reduced-motion: no-preference)`; контент без анимаций виден.
- Недостающие данные — заметная заглушка `<span class="todo">[...]</span>`; перечень в разделе «Заглушки» ниже.
- Фото 16.jpg (`meme-capybara-sunglasses.jpg`) — только на 404. Фото с детьми на сайте — до письменного согласия родителей публиковать нельзя (см. «До публикации»).

## Review Focus

1. Телефон 360 px: hero не выходит за экран, кнопка и цена видны без прокрутки, нет горизонтальной прокрутки.
2. Браузер без `animation-timeline` или с `prefers-reduced-motion: reduce`: весь контент виден, hero-фото не двигается.
3. Фото не загрузилось: у всех `<img>` есть `alt`, `width`/`height` (нет скачков вёрстки), фон-заглушка.
4. Restoplace недоступен: рядом с кнопкой покупки есть телефон и Telegram.
5. Логотип на светлой шапке читаем (зелёная версия), на зелёном hero/подвале — белая.
